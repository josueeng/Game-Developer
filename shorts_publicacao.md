# Shorts: títulos e descrições

Cada Short é um trecho contínuo do vídeo completo (mesma narração, mesmas
cenas, mesmas fontes), reenquadrado na vertical. Arquivos em
`<projeto>/out/shorts/<id>.mp4` (gerar com `npm run shorts` em cada projeto).

Dica: em cada Short, use "Vídeo relacionado" no YouTube Studio para ligar ao
vídeo completo.

---
